GFX 100s II

All 12 Custom Slots — Build Guide

v3 — final audit
Notes that apply to every slot
Custom name display: The custom slot name you assign (TRIPOD, BRACKET, etc.) is stored in the camera but does NOT appear in any shooting display. The camera always shows C1, C2, etc. on both the e-ink top screen and rear LCD. The name is only visible inside Menu → I.Q. → Edit/Save Custom Setting.
Sleep behavior: When Auto Update is Disabled, the camera reverts to saved slot settings on sleep. Temporary in-field adjustments (aperture, ISO, exposure comp) reset on sleep. This is by design — not a malfunction. Re-save the slot if you want changes to persist.
Self-timer: Set Save Self-Timer Setting to OFF globally. Turn the self-timer on manually when you mount the tripod in C1 or C4, and off when you move away. This prevents timer bleed into action and event slots.
Performance Boost: Global only — cannot be saved per slot. Default: AF Priority Normal. Change manually to AF Priority Low Light before PSO or dark stage shoots (C6 Still). Assign to a function button for fast field access.
Purple labels = menu paths documented but not yet physically verified on your camera. Confirm when you first build that slot and report back for correction if needed.
